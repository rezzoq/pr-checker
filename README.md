# PR Checker

Локальная Java CLI-утилита: получает diff через Git, выполняет простые проверки и отправляет изменения локальной LLM. Реализация для Ollama подключена через интерфейс `LlmClient`; источник diff также задаётся интерфейсом `DiffSource`.

## Запуск

Требуются JDK 21+, Maven и Git. Из корня репозитория:

```shell
mvn test
mvn exec:java -Dexec.args="main"
mvn exec:java -Dexec.args="main review.md"
```

Аргументы: базовая ветка (по умолчанию `main`) и необязательный путь отчёта. Без пути отчёт выводится в консоль.

По умолчанию Ollama доступна на `http://localhost:11434`, модель — `qwen2.5-coder:7b`. Настройки:

- `OLLAMA_BASE_URL` — адрес Ollama.
- `OLLAMA_MODEL` — имя установленной модели.
- `PR_CHECKER_MAX_CHUNK_CHARS` — максимальный размер diff-части одного запроса в символах (по умолчанию `12000`).

Файлы из diff объединяются в запрос до лимита; каждый чанк отправляется отдельным запросом. Файл, превышающий лимит сам по себе, пропускается целиком и указывается в отчёте. Rules анализирует исходный diff ровно один раз; замечания модели из всех чанков выводятся подряд без дополнительной сводки.
